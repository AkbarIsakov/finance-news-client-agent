# Task 1. Извлечение компаний, отраслей и цитируемости новостей

## Что лежит в папке

- `task1_pipeline.ipynb` - полный ход обработки: очистка -> NER компаний -> группировка новостей в события -> классификация отрасли для группы -> подсчёт цитируемости.
- `data/news.csv` - исходный датасет, не исправленные предсказания.
- `results/news_predictions.csv` - результат работы модели.

## Как решали

1. **Очистка:** HTML, служебные заголовки, дубли начала новости. Исходные три столбца сохраняются без изменений.
2. **Компания:** русскоязычный Natasha NER (`ORG`) + нормализация имен + исключение ведомств/СМИ, выступающих как источник публикации. Необнаруженную компанию обозначаем «Не указана».
3. **События:** мультиязычные эмбеддинги SentenceTransformer, ограничение ложных объединений по географии/фактам. Сообщения о событии, причинах и последствиях объединяем при достаточном подтверждении совпадения.
4. **Отрасль:** ансамбль семантического сходства, zero-shot NLI и описаний типов событий; для многопубликационной группы усредняем несколько разноплановых публикаций и назначаем одну отрасль всему `event_id`.
5. **Цитируемость:** нормализуем адрес `source` до издателя (Telegram-каналы отдельно); `citation_count` — число уникальных издателей, `articles_count` — число публикаций события. Это не количество буквальных цитат.

## Запуск на Mac

```bash
cd task1
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
jupyter notebook task1_pipeline.ipynb
```

Результат пишется в `results/news_predictions.csv`. 
Выходная таблица содержит исходные `title`, `text`, `source` и шесть дополнительных полей: `company`, `companies`, `industry`, `event_id`, `citation_count`, `articles_count`.

## Как проверяли качество

- Отрасли: accuracy и macro-F1 относительно рабочей эталонной разметки.
- События: Adjusted Rand Index и pairwise precision/recall/F1.
- Компании: нормализованное совпадение названий с отдельно проверенным набором случаев.
- Цитируемость: точное совпадение количества издателей/публикаций в группах.

Важные ограничения: нет некоторых фактических рубрик (медицина, спорт, происшествия); определение компании и границы событий могут быть неоднозначными.
