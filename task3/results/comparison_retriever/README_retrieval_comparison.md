# Эксперимент 2 — увеличение boost заголовка

**Цель:** проверить, повысит ли усиление совпадений по заголовку релевантность найденных новостей о клиенте.

**Изменение:** в поисковом запросе OpenSearch (`task2/src/retrieval.py`) вес поля `title` повышен с **`boost: 4` до `boost: 8`**; вес поля `content` оставлен **`boost: 1`**. Остальные параметры при корректном A/B-сравнении должны быть одинаковыми.

**Результат:** 8 клиентских тестов; точность отобранных новостей (`selected_news_precision_judged`) **0,7917 → 0,9048**, но общий балл **0,9332 → 0,8382** (Δ −0,0950), `product_ndcg_at_3` **0,9558 → 0,8308**, доля корректных PPTX **1,00 → 0,875**; критических ошибок **0 → 1**. Вердикт валидатора: **worse**.

**Вывод:** повышение веса заголовка улучшило точность отбора новостей на контрольных примерах, но общий результат ухудшился. По этому прогону менять базовую настройку без дополнительной проверки не стоит.
