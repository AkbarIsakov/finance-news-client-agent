# Эксперимент 1 — изменение system prompt

**Цель:** проверить, улучшит ли более подробный промпт обоснование финансовых продуктов и качество клиентских презентаций.

**Изменение:** в `task2/src/writer.py` заменён `system` на расширенные инструкции: использовать только входные данные, не выдумывать факты, связывать продукт с риском клиента, указывать условия применимости и задавать три вопроса для встречи. Формат ответа — строго JSON с полями `summary`, `product_fit` и `questions`. Полный текст сохранён в [`candidate_system_prompt.py`](candidate_system_prompt.py).

**Результат:** 8 клиентских тестов; общий балл **0,9332 → 0,4355** (Δ −0,4977), `product_ndcg_at_3` **0,9558 → 0,4635**, доля корректных PPTX **1,00 → 0,50**; критических ошибок **0 → 4**. Вердикт валидатора: **worse**.

**Вывод:** в этом прогоне изменение промпта ухудшило общий результат. Перед внедрением нужно проверить ошибки JSON-контракта и генерации презентаций.
