# Task 2. RAG-агент для подготовки клиентских презентаций

## Что где находится

- `src/data.py` — клиенты, новости, справочники и нормализация издателей.
- `src/retrieval.py` — OpenSearch/BM25, настройки поискового запроса и чанкинга; `LocalRetriever` для демонстрационного запуска.
- `src/recommend.py` — подбор продуктов по профилю/заметкам и проверка релевантности новостей.
- `src/writer.py` — GigaChat, инструкции/промпт, структурированный JSON с обоснованиями.
- `src/presentation.py` — создание реального `.pptx`, слайды, тема оформления.
- `src/cli.py` — `index`, `list-clients`, `demo`, `generate`.
- `config/prompts/` — альтернативный промпт для A/B эксперимента.
- `data/` — четыре входных файла задания; `examples/` — готовые презентации.
- `outputs/` — создаётся при запуске; исключена из Git по умолчанию.

## Порядок работы

Определение клиента -> поиск клиентского профиля, заметки, продуктов и новостей в OpenSearch -> ранжирование подходящих финансовых продуктов и новостей -> ограниченная генерация текста в GigaChat -> редактируемая 7-слайдовая презентация PowerPoint и JSON-след решения.

## Установка (macOS)

```bash
cd task2
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
```

```bash
# запусти Docker Desktop
 docker compose up -d
curl http://localhost:9200
python -m src.cli index
python -m src.cli list-clients
python -m src.cli generate "Подготовь презентацию о РЖД"
```

После первого создания индекса не нужно повторять `index`, если меняются только промпт, веса поискового запроса или оформление PPTX. При изменении исходных данных или чанкинга необходимо переиндексировать документы. Команда `index` удаляет и создаёт индекс указанного имени: для A/B теста чанкинга используй отдельные индексы.

**Демонстрационный режим без Docker/GigaChat** (не тестирует обязательные внешние компоненты):

```bash
python -m src.cli demo "Подготовь презентацию о РЖД"
```

Результат — `outputs/*.pptx` и соответствующий `outputs/*.json`.

## Настройки для экспериментов

| Переменная | Где применяется | Нужно ли переиндексировать? |
|---|---|---|
| `GIGACHAT_PROMPT_FILE` | Инструкции GigaChat (`src/writer.py`) | Нет |
| `NEWS_QUERY_MODE` | `balanced` / `title_only` | Нет |
| `NEWS_TITLE_BOOST`, `NEWS_CONTENT_BOOST` | BM25-веса полей | Нет |
| `NEWS_CHUNK_SIZE`, `NEWS_CHUNK_OVERLAP` | Разбиение новостей на части перед индексацией | **Да, в отдельный индекс** |
| `OPENSEARCH_INDEX_NAME` | Выбор индекса | Создать индекс, если отсутствует |
| `PPTX_THEME` | Палитра презентации, `teal` / `blue` | Нет |
